# ToDo App

A simple ToDo application built with React and Tailwind CSS.

## Features

- Add new tasks
- Mark tasks as completed (with strikethrough)
- Delete tasks
- Automatic saving to localStorage (persists across page refreshes)
- Mobile-friendly design
- Clean blue-themed UI

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage

- Enter a task in the input field and click "추가" (Add) to add it to the list.
- Check the checkbox to mark a task as completed.
- Click the "✕" button to delete a task.
- Tasks are automatically saved to your browser's localStorage.
